Install Pluto

Open Terminal on your Mac: press Command (⌘) + Space, type “Terminal,” and press Return. Click Copy command below, paste it into Terminal with Command + V, then press Return. Wait for Pluto to install and open.

curl -fsSL https://raw.githubusercontent.com/metagrover/pluto/master/scripts/install-macos.sh | bash

Follow Pluto’s setup to download its speech models and allow microphone and system audio access. Calendar access is optional.

Set up Ollama

Download Ollama for Mac, move it into Applications, and open it. Follow its prompt to enable the ollama Terminal command.

Ollama runs the AI that writes notes and answers questions on your Mac. Keep it open. Copy this command into Terminal and press Return to download Pluto’s two language models, then wait for both downloads to finish:

ollama pull gemma4:12b && ollama pull phi4-mini:3.8b

Pluto’s speech models handle transcription; Ollama’s models handle notes and chat. Downloads can take several minutes.

Pluto uses Ollama and these models by default—no settings to enter for a new setup.

Try your first recording

Keep Ollama running and open Pluto. Let everyone know you’re recording, then start a short recording. Stop it and wait for Pluto to finish generating the notes.

Open the meeting to review its notes. You now have context to ask about in Pluto—or, if you choose, in ChatGPT.

Connect ChatGPT · optional

Use your saved meeting notes to discuss priorities, compare conversations, or draft follow-ups in ChatGPT Work. You can use Pluto on its own without this connection.

Before you connect

You need Pluto and the ChatGPT desktop app installed on the same Mac, with Pluto running. Get the ChatGPT desktop app and sign in. Use a current version that supports local plugins and ChatGPT Work on your computer.

This setup uses the desktop app to reach the notes on your Mac. Opening ChatGPT in a web browser alone won’t connect it to Pluto.

What you’re sharing

Enabling the connection makes all your meeting notes available to read. Notes ChatGPT retrieves are sent to OpenAI and become part of that conversation. Raw transcripts and recordings are excluded, and the plugin cannot change your meetings.

Choose Disable access in Pluto’s ChatGPT connection settings to stop future reads. Notes already shared in ChatGPT remain there.

Set it up once

  1. In Pluto, open Settings → Advanced → ChatGPT connection.
  2. Read the sharing explanation, check the box to allow meeting-note access, then click Connect to ChatGPT. Pluto installs the plugin for you.
  3. When Pluto shows Local setup complete, fully quit ChatGPT with ⌘Q and reopen it. Opening another window isn’t enough.
  4. In the ChatGPT desktop app, select ChatGPT, switch to Work, and start a new chat that works locally on this computer. Keep Pluto open and your Mac awake.
  5. Type @Pluto and select the Pluto plugin, then ask a question. Review any access prompts from ChatGPT.

Try asking

@Pluto what should I focus on?

Or ask “What follow-ups did I commit to this week?” or “What changed across my last three planning meetings?” Ask ChatGPT to use your meeting notes and name the meetings behind its answer. Record a meeting and let Pluto generate its notes first so there’s something to read.

See OpenAI’s ChatGPT Work instructions and plugin guide. Availability can depend on your account and workspace settings.

If you get stuck

ChatGPT can’t find Pluto or read my notes

Keep Pluto open with meeting-note access enabled. Fully quit ChatGPT with ⌘Q, reopen it, and start a new local Work chat. Mention @Pluto again. Check that the meeting you want has generated notes.

If setup failed, update the ChatGPT desktop app and check that your account or workspace allows local Work plugins. In Pluto, choose Disable access, then connect again. “Local setup complete” confirms installation; your first successful question confirms ChatGPT can read the notes.

Ollama isn’t connecting or a model is missing

Open Ollama and run ollama list to check both models are installed. If you previously changed providers or models, choose Ollama in Settings → Intelligence, with gemma4:12b for Local Analysis & Deep Model and phi4-mini:3.8b for Fast Chat Model. If Terminal says “command not found,” finish Ollama’s command-line setup and reopen Terminal. See Ollama’s Mac instructions.

If your Mac struggles, use a smaller model from Ollama’s library and enter its exact name in Pluto.

There’s no audio or transcript

Finish Pluto’s speech-model setup and check your microphone. Review permissions in System Settings → Privacy & Security, then return to Pluto and choose Check again. If you previously denied microphone access and enable it in Settings, restart Pluto.

Database setup and installer details

Choose Standard or Encrypted during Pluto’s setup. Encrypted setup encrypts the database and uses macOS Keychain; it may ask for permission. The choice is fixed for the profile. Audio files are not encrypted by default.

The installer verifies the release and removes only Pluto’s download quarantine. It does not grant recording permissions or disable protections for other apps. Read the installer. Quit Pluto before upgrading; your profile and speech models are preserved. Updates may ask for permissions again.

Prefer a manual download?

Download the Mac DMG and drag Pluto into Applications. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway. The release is ad-hoc signed, not notarized. See the full manual instructions.
