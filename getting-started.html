Three steps to local notes and chat: Pluto, Ollama, and a quick connection.

Apple Silicon · macOS 14.2 or later · Internet needed for initial downloads

Install Pluto

Paste this into Terminal and press Return. Pluto installs and opens.

curl -fsSL https://raw.githubusercontent.com/metagrover/pluto/master/scripts/install-macos.sh | bash

Follow Pluto’s setup to download its speech models and allow microphone and system audio access. Calendar access is optional.

Set up Ollama

Download Ollama for Mac, move it into Applications, and open it. Follow its prompt to enable the ollama Terminal command.

Keep Ollama open. Run this to download Pluto’s two language models, then wait for both downloads to finish:

ollama pull gemma4:12b && ollama pull phi4-mini:3.8b

Pluto’s speech models handle transcription; Ollama’s models handle notes and chat. Downloads can take several minutes.

Connect & record

In Pluto’s Settings → Intelligence, choose Ollama and enter:

Local Analysis & Deep Model
gemma4:12b
Fast Chat Model
phi4-mini:3.8b

Keep Ollama running, start a short recording, and check the live transcript. Let everyone know you’re recording. Stop to generate notes, then try a question in Ask Pluto.

If you get stuck

Ollama isn’t connecting or a model is missing

Open Ollama, run ollama list, and check that the model names match Pluto’s settings. If Terminal says “command not found,” finish Ollama’s command-line setup and reopen Terminal. See Ollama’s Mac instructions.

If your Mac struggles, use a smaller model from Ollama’s library and enter its exact name in Pluto.

There’s no audio or transcript

Finish Pluto’s speech-model setup and check your microphone. Review permissions in System Settings → Privacy & Security, then return to Pluto and choose Check again. If you previously denied microphone access and enable it in Settings, restart Pluto.

Database setup and installer details

Choose Standard or Encrypted during Pluto’s setup. Encrypted setup encrypts the database and uses macOS Keychain; it may ask for permission. The choice is fixed for the profile. Audio files are not encrypted by default.

The installer verifies the release and removes only Pluto’s download quarantine. It does not grant recording permissions or disable protections for other apps. Read the installer. Quit Pluto before upgrading; your profile and speech models are preserved. Updates may ask for permissions again.

Prefer a manual download?

Download the Mac DMG and drag Pluto into Applications. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway. The release is ad-hoc signed, not notarized. See the full manual instructions.
