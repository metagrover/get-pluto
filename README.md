# Pluto Website

The official product landing page for **Pluto** — the private, open-source second brain for work on macOS.

## Overview

Pluto connects conversations across people, projects, and commitments — giving knowledge workers an intelligent working memory that keeps them prepared and accountable.

This repository hosts the static marketing and product landing page for Pluto.

## Features

- **Executive Aesthetic**: Bespoke Warm & Sophisticated design language (Midnight Blue, Champagne Gold, Warm Cream).
- **Interactive Product Stage**: Live three-stage workflow demonstrator (Pre-Meeting Brief, Live Voice ID, Live Documents & Actions).
- **Interactive Spotlight Search**: Demonstrates on-device instant recall (`⌘K`).
- **Ambient Motion Graphics**: Interactive background constellation graph and delicate corner astrolabes.
- **Zero Build Step**: Pure HTML5, modern CSS3 with custom properties, and vanilla JavaScript. Deploys seamlessly to any static host (GitHub Pages, Cloudflare Pages, Vercel).

## Local Development

Start any static HTTP server:

```bash
# Using Python
python3 -m http.server 4173

# Or using npx
npx serve .
```

Open `http://localhost:4173` in your browser.
